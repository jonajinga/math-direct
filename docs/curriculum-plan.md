# Math Direct: Evaluation and Plan

## A complete Direct Instruction program for Pre-K, Kindergarten, and First Grade

Prepared October 2026. Everything in Part 1 was checked against the code and the generated lessons in this repository. Part 2 is the plan.

> **Status, October 2026: built, and rebuilt for the phone.** The plan below has been carried out, and the site was then rebuilt phone-first: no paper, no numeral writing, no dark mode, every control at the bottom, the first try scored, a retest after each correction, four to eight items in each mastery test part, and an On your own segment at the end of most lessons. See docs/design.md for the current design. The program now has Pre-K (100 lessons), Kindergarten (140), First Grade (150), and the Bridge (20), with 41 mastery tests, a placement test, worksheets, practice, fact review, and the teacher dashboard. The decisions in section 2.6 were made as recommended: printing was restored for worksheets and materials only; progress saved under the old program is kept and shown on the dashboard, with the placement test suggested for finding the new starting lesson; money is included as an optional First Grade track; and the old 150 lessons were retired, with their addresses redirected. Part 1 describes the old program and is kept as a record. See README.md for how the curriculum is built.

---

## Summary

Math Direct has a sound foundation. The lesson screen, which puts the child's display above the parent's script, is the right design for one adult teaching one child. The Say, Do, Praise, and Correct format is right. The generator script, which builds all 150 lessons from code, makes large changes possible without editing thousands of lines by hand. Profiles, notes, export, and offline use already work.

The trouble lies in the teaching itself, and in coverage. Most new skills are stated once and then tested, with no "my turn, together, your turn" sequence. Most corrections do not model the answer. Counting tasks show the numeral, so a child can read the answer instead of counting. Several features are broken: the 25 practice sets draw from only seven pools of problems, and the place value chart renders nothing. And the program covers only number and operations. It has no shapes, measurement, time, data, patterns, sorting, or numeral writing, which together make up a large share of what Pre-K, Kindergarten, and First Grade children are expected to learn.

The plan below keeps the lesson screen, the generator approach, and the record keeping. It replaces the seven topic "phases" with three levels (Pre-K, Kindergarten, First Grade), each built the way Engelmann's own programs are built: every lesson is a set of short exercises drawn from several skill tracks that run in parallel over many lessons. It adds mastery tests, a placement test, error recording, printable independent work, and the visual aids the new content needs. It removes the streaks, scores, and grade words that now appear in practice and flashcards.

## 1.2 What works well and should be kept

1. **The two-panel lesson screen.** The child sees large numbers and pictures; the parent reads the script below. This is the right arrangement for home teaching.
2. **The step format.** Each step has what to say, what to do, what to say if the child is right, and what to say if the child is wrong. This is the skeleton of a Direct Instruction script.
3. **Generated lessons.** Building lessons from code means review schedules and number choices can be changed across hundreds of lessons at once. The deterministic shuffle means a lesson is the same every time it is taught, which matters when a parent repeats a lesson.
4. **Dot patterns in rows of five.** Arranging dots in fives and tens prepares the child for ten-frames and place value.
5. **Profiles, notes, export, and offline use.** Two children can be tracked separately, and nothing depends on an account or a server.
6. **A sensible order for number and operations.** Numbers before addition, addition before subtraction, +1 before +2, facts before two-digit work. The broad order is defensible; the problems are in how each step is taught.

## 1.3 Defects: things that are broken now

1. **The 25 practice sets are really 7.** The practice layout loads every problem for the page's phase: `problemSets | where("phase", phase)` (`src/_includes/layouts/practice.njk:15`). "Addition to 5" therefore serves all 65 Phase 3 problems, including sums to 10 and number bonds. The four Phase 3 pages are identical, and so are the pages within every other phase. The ten problems written in each practice page's own file are never shown, because the layout does not print the page content.
2. **The place value chart is blank.** Lessons 86 to 89 use the `placevalue` visual, and the script says "Point to tens column, then ones." The engine renders nothing for that visual (`src/assets/js/lesson-engine.js:246`).
3. **The end-of-lesson practice round is empty.** The lesson page has a "Practice Round: Try these on your own!" section (`src/_includes/layouts/lesson.njk:109`), but nothing ever fills it. The completion screen replaces it.
4. **A question that does not match its display.** In the number bond lessons, the parent asks "What makes five? Two plus?", which asks for the missing 3, while the screen shows `2 + 3 = ?`, which asks for the sum, 5 (generator line 1024; lesson 60, steps 6 to 8).
5. **Word problems give away the operation.** All 30 word problems in lessons 145 to 149 show the equation, such as `43 − 28 = ?`, on the child's screen while the parent reads the story (generator line 1739). The hard part of a word problem is deciding what to do, and the screen does it for the child.
6. **Answers are guessed from display text.** When a step has no stored answer, the engine works one out by pattern-matching the displayed text (`computeAnswer`, `lesson-engine.js:344`). This works for simple equations but is fragile, and it is how the mismatch in item 4 went unnoticed.

## 1.4 Teaching design problems

These are the issues that most separate the current lessons from a strong Direct Instruction program.

1. **New skills are not modeled, led, and tested.** A Direct Instruction exercise introduces something new in three moves: the teacher shows it ("My turn"), teacher and child do it together ("Say it with me"), and then the child does it alone ("Your turn"). In these lessons, new material usually gets one sentence of explanation and then questions. Lesson 41, which introduces +1, has no teaching step at all: after four review items it simply asks "Six and one more. How many altogether?" Lessons 100 and 101, which open addition and subtraction within 20, also contain no model. Lesson 70 introduces −2 with a single sentence.
2. **Strategies are used before their preskills are taught.** Lesson 45 tells the child to "count on from eight: nine, ten." No earlier lesson teaches counting forward from a number other than one, which is the preskill that counting on depends on. The only earlier change from counting up from one is a single step of counting backward in each of lessons 6 and 8.
3. **Corrections usually do not correct.** In a Direct Instruction correction, the teacher says the right answer, has the child say it, and later returns to the item. In 256 steps across 124 lessons, the correction line is a placeholder such as "Good." or "Correct." For example, in lesson 41, step 4 shows 15 dots; if the child is wrong, the script says "Good."
4. **The numeral and the quantity are shown together.** Of the 880 steps that show dots and ask how many, 691 also show the numeral, so the child can read the answer instead of counting. The reverse also happens: when the parent asks "What number is this?", dots appear under the numeral by default (`showAutoDots = true`, `lesson-engine.js:255`), so the child can count instead of reading. Number reading and counting are separate skills, and each must be tested alone before the two are joined.
5. **Rules are rarely stated.** Direct Instruction gives the child a short, exact rule and then many examples. "When you plus one, you say the next number" turns +1 into something a child already knows how to do. The current lessons describe each fact but seldom give the rule that produces it.
6. **Lessons are blocked by topic.** Lessons 21 to 30 each introduce one number from 11 to 20. Lessons 41 to 44 are all +1; 45 to 48 are all +2. Engelmann's programs do the opposite: each skill runs as a track across many lessons, and each lesson contains short exercises from four to eight tracks. A child might count to 30, read numerals, solve a +1 fact, and do a shapes exercise in the same ten minutes. This spreads practice over time, which is what produces lasting memory.
7. **Confusable items are taught together.** Lesson 18 introduces both > and < at once, and the only distinction offered is the name. Direct Instruction separates confusable items, teaches one until it is firm, and gives the second a clear rule that distinguishes it.
8. **Two-digit regrouping is taught by ear.** Lessons 130 to 144 teach carrying and borrowing entirely in spoken sentences ("Ones: two minus seven, we can't do that! Borrow a ten."), with the problem written horizontally and no place value picture. Regrouping depends on seeing tens and ones lined up in columns.
9. **Word problems are not taught by type.** Children need to learn to recognize kinds of problems: adding to, taking from, putting together, taking apart, and comparing, with the unknown in different places. The current word problems are a mixed list, with numbers far beyond first-grade range (17 + 16, 43 − 28).
10. **There is no mastery check and no remedy.** A parent can mark a lesson complete whether or not the child learned it. There are no tests every ten lessons and no guidance on what to reteach after an error.
11. **Praise is effusive and generic.** The praise lines include "Fantastic!", "Brilliant!", "Super job!", and "You're getting so good at this!" (`PRAISE_GREAT`, generator line 118). Direct Instruction praise is short and names the work: "Yes. Seven." Generic excitement adds nothing a child can learn from and can make correct answers feel like a performance.

## 1.6 Game-like elements to remove

You asked for no gamification. These are the elements in the current code that work like a game:

- **Practice engine** (`src/assets/js/practice-engine.js`): a running "streak" counter, a "hot" style when the streak reaches three, a "Best Streak" result, a percentage score, and grade headings ("Perfect!", "Great job!", "Good effort!", "Keep practicing!").
- **Flashcards** (`src/assets/js/flashcards.js:281`): a running "correct" counter, a percentage score, and the same grade headings.
- **Lesson praise lines**: the `PRAISE_GREAT` pool of exclamations in the generator.
- **The final lesson's title**, "Math Master!" (generator line 1785).
- **The completion screen**, "Lesson N Complete! Great work!"
- **The home page**, which advertises "scoring, and streak tracking" (`src/index.njk:87`).

Records of right and wrong answers are still valuable, but they belong in the parent's view, as information for teaching decisions, not on the child's screen as a score.

## 1.7 Claims on the site that are not accurate

- The home, about, and curriculum pages say the program is for ages 5 to 10 and grades K to 4 (`src/pages/about.njk:10`; `src/_data/phases.js:180`). The content ends at second-grade work.
- The teacher guide lists keyboard shortcuts that do not exist (N, P, D, and ?) and says the space bar reveals the answer. In the engine, the space bar replays the dot animation.

# Part 2. The Plan

## 2.1 Principles

Every decision below follows from these rules.

1. **Teach so the child cannot misunderstand.** Engelmann's principle: if the child has not learned, the teaching was not clear enough. Each new item gets a model, a lead, and a test, followed by a delayed test later in the same lesson.
2. **Teach preskills first.** No strategy appears before the skills it depends on are firm. Counting forward from any number comes before counting on; partners of ten come before making ten; reading two-digit numerals comes before adding them.
3. **Give rules and a full range of examples.** A rule the child can say ("Plus one is the next number"), many examples that fit it, and, for concepts like shapes and "more," clear non-examples that show where the concept stops.
4. **Separate what is easily confused.** Six and nine, two and five, greater and less, plus and minus are introduced apart and joined only once each is firm.
5. **Spread practice across tracks and lessons.** Each lesson has four to eight short exercises from different tracks. A skill is introduced, practiced daily for several lessons, then reviewed at widening intervals, and it never disappears.
6. **Correct every error the same way.** Model the answer, have the child say it, start the exercise over, and return to the item later.
7. **Advance only on mastery.** A mastery test every ten lessons decides whether the child moves on, and tells the parent exactly what to reteach.
8. **No games.** No points, streaks, scores, badges, sounds, characters, or celebrations. The child's reward is being able to do the work. Praise is short and names what was done.
9. **Pre-readers come first.** Nothing on the child's screen requires reading words. The parent speaks every instruction.

## 2.2 Structure of the program

### Three levels and a bridge

| Level | Typical age | Lessons | Daily time | Ends with |
|---|---|---|---|---|
| Pre-K | about 4 | 100 | 10 to 12 minutes | Counting to 20, numerals to 10, quantities to 5 at a glance, shapes, patterns, joining and separating within 5 |
| Kindergarten | about 5 | 140 | 15 to 20 minutes | Kindergarten standards met, including fluency within 5 |
| First Grade | about 6 | 150 | 20 to 30 minutes | First grade standards met, including fluency within 10 |
| Bridge to Second Grade (optional) | | about 20 | 20 to 30 minutes | Two-digit adding and subtracting with regrouping |

A school year has about 180 days. These counts leave room for repeated lessons, mastery-test remedies, and ordinary interruptions, so a child can finish a level in a year without hurry.

### Anatomy of a lesson

Each lesson is a short series of exercises. Each exercise belongs to one track, takes one to four minutes, and is one of four kinds:

- **New teaching**: model, lead, and test a new item, written by hand for each case.
- **Firming**: quick items on what was taught in the last few lessons, mixed with older items.
- **Review**: older material, scheduled at widening intervals.
- **Independent work**: something the child does alone, on paper or on screen, which the parent then checks.

The parent's panel shows the exercise name, the step within it (My turn, Together, Your turn), the exact words to say, what the child should say, and a correction written for that exercise. A lesson outline at the top lets the parent see the whole lesson before starting.

### Tests

- **Placement test**: a short oral test for each level that recommends a starting lesson. With two children, this matters: each starts where she is.
- **Mastery test every ten lessons**: a few items from each active track, a pass mark, and a remedy table that names the exercises or lessons to repeat for each missed item.
- **End-of-level test**: covers the whole level and confirms readiness for the next.

## 2.4 What the app must do

### Lesson engine

1. **Exercises within lessons.** A lesson is a list of exercises; each has a track, a kind, and its steps. The parent's panel shows the exercise title, the My turn, Together, or Your turn cue, and a lesson outline.
2. **Recording answers.** Each test step has two large buttons for the parent: "Firm" and "Error." An error shows the correction script, offers to start the exercise over, and places a retest of that item near the end of the lesson. Results are saved to the child's profile by lesson, exercise, item, and date.
3. **Control over what the child sees.** Each step states whether the child sees the numeral, the quantity, or both. Reading tasks show the numeral alone; counting tasks show the quantity alone. The global dots switch stays, but steps can override it.
4. **Brief showing.** For "small amounts at a glance," a quantity appears for a set time, about a second and a half, then disappears.
5. **Pointing answers.** The child can answer by pointing to one of two to four large choices on the screen. This lets pre-readers answer without typing.
6. **Stored answers only.** Every step stores its answer; the engine stops guessing answers from display text.

### Visual aids, in the order they are needed

- **For Pre-K**: simple pictures of objects for counting and stories; scattered and circular arrangements; five-frames; brief showing; shapes in many sizes and turns, with non-examples; side-by-side bars and objects for size comparisons; pattern strips; pointing choices.
- **For Kindergarten**: ten-frames; number families; teen numbers as a full ten-frame and some more; objects that move away for "taking away"; solid shapes.
- **For First Grade**: tens-and-ones drawings (sticks and dots) and a working place value chart; problems in columns; clock faces; tally charts and picture graphs; shapes cut into halves and fourths; true and false equation cards; coins.

### Lesson data and the generator

1. **A new data model**: level, then lesson, then exercises, then steps, with a track named on every exercise.
2. **A scope and sequence file for each level**: each track's items, the lesson where each is introduced, and its review schedule. The generator builds every lesson from these schedules, so the mix of new and review material in each lesson comes from one place.
3. **Hand-written new teaching**: every new-teaching exercise is written by hand. The generator fills in firming and review.
4. **A checking script that fails the build** when an answer is wrong, a correction does not state the answer, a counting step shows the numeral, a new item lacks a model, lead, and test, a track item goes unreviewed too long, or a lesson runs longer than its time allows.

### Parent tools

1. **Placement test, mastery tests, and remedy tables**, as described in 2.2.
2. **A better teacher dashboard**: each child's current lesson, mastery test history, tracks with frequent errors, a grid of which facts are firm, and the existing notes.
3. **Printable materials**: an independent work page for each lesson (writing numerals, circling, matching, drawing), printable dot cards, ten-frames, and number cards, and a record sheet for mastery tests. Printing was removed in an earlier commit (67e572c). I recommend bringing it back for this narrow purpose, because writing numerals takes a pencil and paper.
4. **A rewritten teacher guide**: how to give a cue so the child answers after thinking rather than guessing, the correction procedure, mastery rules, pacing, and accurate keyboard shortcuts.

### Practice and flashcards

1. Each practice set uses its own problems.
2. For Pre-K and Kindergarten, practice is led by the parent: the screen shows an item, the child answers aloud or points, and the parent taps Firm or Error. Typing a number is reserved for children who can write numerals.
3. Streaks, scores, percentages, and grade words are removed. Results go to the parent's dashboard.
4. Each practice set names the lesson after which it should be used.
5. In First Grade, a short daily fact review is built from the facts taught so far, with recently missed facts appearing more often.

## 2.5 Order of work

Each stage ends with something usable, so teaching can continue throughout.

## 2.6 Decisions for you

These choices are yours to make, and they change what is built first.

1. **Your daughters' ages and starting points.** If either is about four, Pre-K should be built first. If both are five or older, Kindergarten should come first and Pre-K can follow.
2. **Printable pages.** I recommend restoring printing for independent work pages, mastery test records, and manipulatives, since numeral writing needs paper. This reverses an earlier decision, so it is your call.
3. **Lesson addresses and saved progress.** Moving from phases to levels changes lesson web addresses (for example, `/k/lesson-12/` instead of `/lessons/lesson-12/`). Existing saved progress would need to be carried over. If your daughters have progress saved now, I will write that conversion.
4. **Money in First Grade.** It is optional under the Common Core and easy to include as a short track.
5. **Keeping the old lessons available.** The old 150 lessons can stay in place until each level is ready, or be retired as soon as Stage 1 is done.
